# Automation-Toolkit

Colección de scripts y herramientas de automatización orientadas a soporte IT, infraestructura, monitoreo y administración de sistemas.

---
## Objetivo

Este repositorio reúne soluciones desarrolladas para automatizar tareas operativas, mejorar tiempos de respuesta y reducir la intervención manual en entornos de TI.

---
## Proyectos

### Web-Service-AutoRecovery
Script de monitoreo y recuperación automática de servicios web mediante validaciones HTTP.

**Características:**
- Monitoreo continuo vía HTTP.
- Control de fallos consecutivos.
- Reinicio automático controlado.
- Validación posterior al arranque.
- Visualización de logs del servidor.
- Prevención de reinicios paralelos.

## Tecnologías
- PowerShell
- Windows Server
- HTTP Monitoring
- Automatización IT
