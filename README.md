# Automation-Toolkit

Colección de scripts y herramientas de automatización orientadas a infraestructura, operaciones TI, monitoreo, administración de sistemas y ciberseguridad.

---
## Objetivo

Este repositorio reúne soluciones desarrolladas para automatizar tareas operativas, mejorar la eficiencia de los equipos de TI, fortalecer la gestión de endpoints y reducir la intervención manual en entornos corporativos.

---
## Proyectos

### Web-Service-AutoRecovery
Script de monitoreo y recuperación automática de servicios web mediante validaciones HTTP.

**Características:**
- Monitoreo continuo vía HTTP.
- Control de fallos consecutivos.
- Reinicio automático controlado.
- Validación posterior al arranque.
- Visualización de logs del servidor.
- Prevención de reinicios paralelos.

**Tecnologías**
- PowerShell
- Windows Server
- HTTP Monitoring
- Automatización IT

---

### Secure-Endpoint-Operations
Solución de automatización para mantenimiento preventivo y optimización controlada de estaciones de trabajo Windows. Diseñada para reducir tareas repetitivas de soporte técnico mediante procesos programados, trazables y ejecutados de forma segura bajo la cuenta del sistema operativo.

**Características:**
- Limpieza automática de Windows Temp.
- Limpieza de temporales de perfiles de usuario.
- Liberación de memoria RAM mediante:
  - Working Sets
  - Standby List
- Ejecución automática mediante Scheduled Tasks.
- Ejecución bajo NT AUTHORITY\SYSTEM.
- Registro de auditoría mediante Historial.log.
- Instalador automatizado.
- Desinstalador automatizado.
- Validación de componentes requeridos.
- Rotación automática de logs.

**Tecnologías**
- Batch
- PowerShell
- Windows Task Scheduler
- Endpoint Management
- Windows Endpoint Administration
- Automation
